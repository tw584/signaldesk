# Contributing to SignalDesk

Thanks for helping make opportunity research more evidence-based.

## Good contributions

- Add a compliant public source connector with graceful rate-limit handling.
- Improve concern-level clustering without merging unrelated complaints.
- Add tests for ranking, deduplication, and feasibility rules.
- Improve accessibility, mobile review, or source transparency.
- Report a false positive with the original evidence links.

## Development

```bash
npm install
npm run dev
npm run build
```

## Pull requests

Keep changes focused. Explain the user problem, what changed, evidence supporting the change, privacy/source-term implications, and validation performed. Never commit credentials, private data, copied datasets, or fabricated examples presented as real evidence.

## Product standard

Repeated demand is necessary but insufficient. A qualified opportunity must also be realistically achievable by one developer in ten working days. Preserve uncertainty when either demand or feasibility is unverified.
